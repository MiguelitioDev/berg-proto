# berg-proto

Protótipo de site para **Berg Abreu Imobiliária** (Aquiraz/CE), feito pela MJStudios.

- Site estático: um único `index.html` com CSS, JS e imagens embutidos (sem build).
- Deploy: Vercel, preset **Other**, sem comando de build, diretório raiz `/`.

## Pendências
- Número completo do WhatsApp: preencher a variável `WHATSAPP` no script do `index.html`.
- Horário de atendimento, valores dos imóveis e fotos em alta resolução.
